# RideApp

A starter repository for RideApp — a project to build a ride-sharing / transportation application. This repository is intentionally minimal to get started. Add your project files under src/ and update this README with project-specific instructions.

Getting started

- Clone the repository:
  git clone https://github.com/gustaroska/rideapp.git
- Create a branch for your work:
  git checkout -b feature/your-feature
- Add your code in the src/ directory and commit.

What I added in this initial commit

- README.md — project overview and basic instructions
- LICENSE (MIT)
- .gitignore — common ignores for common languages and editors
- src/.gitkeep — placeholder folder for source files
